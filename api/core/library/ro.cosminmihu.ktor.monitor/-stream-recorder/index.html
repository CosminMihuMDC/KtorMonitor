StreamRecorder

class StreamRecorder(isWebSocket: Boolean)

Records the frames of a WebSocket or the events of a Server-Sent Events stream for one call.

Events are queued without suspending and written by a single coroutine, so the stored order is the order of the record* calls. The recorder starts persisting once bind is called with the call id; until then events are buffered. Not thread-safe for concurrent writers of the same direction, except for record, which can be called from any thread.

Internal API, do not use directly.
